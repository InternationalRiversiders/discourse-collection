# discourse-collection API 设计

| [05-端点行为-元信息与邀请.md](05-端点行为-元信息与邀请.md) | 改元信息；邀请的发起 / 撤销 / 记录 / 受邀收件箱 / 受理 / 两道时间闸 / staff 自邀接管 |
